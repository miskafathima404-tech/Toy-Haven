# Toy Haven — COMP40053 Assignment 3

This is a redesigned visual version of the **Toy Haven** concept specified in the assignment brief.

## Same assignment concept
- Figurines
- Toys
- Board Games
- Diecast Cars
- Six required pages
- Search and category filtering
- Product modal
- Cart and localStorage
- Checkout validation and order history
- Wishlist / Collection statuses
- Feedback and FAQ
- Responsive design
- PWA structure

## What is different
The redesign uses a different colour palette, product names, original SVG product artwork, typography, spacing and visual styling.

## Run
Open `index.html` with VS Code Live Server.
